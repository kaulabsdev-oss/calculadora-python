# Calculadora Python

Meu segundo projeto em Python, desenvolvido para praticar programação e operações matemáticas.

## Funcionalidades

- Receber dois números
- Somar os valores
- Exibir o resultado

## Como executar

1. Instale o Python 3.
2. No terminal, entre na pasta do projeto.
3. Execute: `python calculadora.py`

## Exemplo de uso

```
Digite o primeiro número: 2
Digite o segundo número: 3
O resultado da soma é: 5.0
```

## O que aprendi

A função `input()` sempre devolve texto. Na primeira versão, somar 2 e 3 dava "23" em vez de 5, porque o Python juntava os dois textos. Corrigi convertendo os valores com `float()` antes de somar.
